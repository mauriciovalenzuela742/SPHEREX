# ADR-000 — Template

> Copy this file as `ADR-00N-<topic>.md`. One ADR per decision that is costly to reverse.
> If the decision can be undone in five minutes, it does not need an ADR: make it and move on.

- **Date:** YYYY-MM-DD HH:MM
- **Status:** proposal / accepted / replaced by ADR-00M
- **Decides:** name of whoever decides (one person, not "the team")

## Context

What problem has to be solved and what constraints there are. In a hackathon, time is the main
constraint: state it with numbers.

## Options considered

| Option | Pros | Cons | Estimated cost |
|---|---|---|---|

## Decision

What is done. One sentence, in the present tense.

## Consequences

What becomes easy, what becomes hard, and **what would have to be undone if we are wrong**.

## When it is reviewed

A specific moment in the plan. An ADR without a review date becomes dogma.
