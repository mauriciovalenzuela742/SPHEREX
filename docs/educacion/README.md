# Educación — aprender lo que el proyecto necesita

> **Estado: PRELIMINAR.** Nadie con criterio astronómico ha revisado estas páginas. Los resúmenes son
> del equipo; las clases a las que enlazan están en nivel **E0** («texto redactado, pendiente de
> revisión disciplinar») en su propio repositorio. Si algo de aquí contradice a `docs/09` o a
> `data/campos_de_prueba.yml`, **mandan esos documentos**.
>
> **Formación independiente, no habilitación profesional.** Esto no da títulos ni autoriza decisiones
> científicas, de ingeniería o de seguridad.

## Para qué sirve

El equipo mezcla gente de datos, de web y de ciencia. Para que el visor no muestre cosas absurdas,
todos necesitan unas pocas ideas de astronomía: coordenadas, el formato de los archivos, qué es
una bandera de calidad, qué es el movimiento propio. Esta carpeta junta tres cosas:

| Archivo | Qué contiene |
|---|---|
| [`RUTA_DE_APRENDIZAJE.md`](RUTA_DE_APRENDIZAJE.md) | 6 módulos cortos. Cada uno dice qué estudiar, en qué clase del programa educativo, y dónde se aplica en este repositorio |
| [`LECCIONES_DEL_PROYECTO.md`](LECCIONES_DEL_PROYECTO.md) | 8 errores y correcciones **reales** de este proyecto, contados como casos de estudio |
| [`GLOSARIO_AMPLIADO.md`](GLOSARIO_AMPLIADO.md) | Continúa el glosario de [`AGENTS.md`](../../AGENTS.md) §7 con los términos que usan los documentos 09 y 10 |

## De dónde viene el material

- **Casos y datos:** salen de este repositorio (`docs/09_EDA_HALLAZGOS.md`, `docs/10_REPARTO_DE_TRABAJO.md`,
  `data/campos_de_prueba.yml`, el traspaso de V2). Cada caso cita su archivo.
- **Clases de estudio:** salen del
  [Programa Integral de Astronomía, Astrofísica, Ciencias Espaciales e Ingeniería Aeroespacial](https://github.com/vladimiracunadev-create/astronomy-astrophysics-space-sciences-aerospace-engineering-learning-program),
  de Vladimir Acuña. Se enlaza cada clase por su ID (por ejemplo `B08-C03`); **no se copia su texto**.

## Cómo usarlo

1. Lee [`LECCIONES_DEL_PROYECTO.md`](LECCIONES_DEL_PROYECTO.md) entero (10 minutos). Son los errores que ya costaron tiempo.
2. Abre la ruta y haz solo los módulos de tu rol (la tabla indica cuáles).
3. Si encuentras un error o una clase útil que falta, abre un PR a esta carpeta con el cambio y la fuente.
